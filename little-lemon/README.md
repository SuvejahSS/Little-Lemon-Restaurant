# Little Lemon HTML/CSS/JS Clone

A standalone responsive restaurant website inspired by the Little Lemon capstone style.

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Included
- Responsive navigation
- Hero section
- Menu cards
- Add-to-cart functionality
- LocalStorage cart persistence
- Reservation form with confirmation modal
- Testimonials
- About section
- Online-order CTA
- Responsive mobile layout

No build tools or npm installation are required.
